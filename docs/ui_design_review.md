# MAGI WebUI 设计评审

评审日期：2026-09-02
评审对象：`src/magi/ui/static/{index.html,styles.css,app.js}`，以源码起的 v2.1.0 实例（`http://127.0.0.1:8738`）。v2.2.0 只改了版本徽标那一行，结论不受影响。
评审人立场：前端工程师的审美评审。不考虑重构幅度，只说"什么是对的、什么是错的、理想形态长什么样"。

## 0. 怎么看的

- 真实浏览器：Institute 浅色 / 深色、EVA 红 / 蓝、GLASS 开 / 关、8 个 tab、体检弹窗、卡片预览弹窗、玻璃调节面板、hover、键盘焦点。视口宽度 1994 / 1532 / 1152 / 846 CSS px。
- headless Chrome（全新 profile，即"新用户默认"）：8 个 tab 各一张、总览与 Melchior 整页长图、390 px 手机宽。截图在 `%LOCALAPPDATA%\Temp\claude\D--AI-Playground-gemini-wiki-skills\9595b059-789c-405b-bb93-a53110863d86\scratchpad\shots\`。
- 代码：一次只读的结构调查（token、字号、间距、组件、断点、`!important`、裸色值），数字见附录。

一个方法学备注：评审中途 Chrome 窗口被遮挡，页面 `visibilityState` 变成 hidden，rAF 被节流到 2 fps、截图超时。这是窗口遮挡造成的，不是页面性能问题，已排除；下面凡是谈性能的地方都不引用那段数据。

## 1. 一句话总评

**底子很好，表达过剩。**

token 化的 Prussian ink 配色、Archivo 只管拉丁字母的 `unicode-range` 策略、全局 `:focus-visible`、衬线阅读弹窗、KaTeX 与 Mermaid 的按需加载，都是有品味的决定。但页面把这些好东西埋在了三层永远在场的仪表盘 chrome、158 张同等分量的玻璃卡片、以及一套"给人看"而不是"给人用"的装饰之下。用户每天真正要做的事（写一句话、拍一个板、看一眼线、读一张卡）在视觉上和"注册项目"、"config.yaml 第 17 项"拿到的是同一级别的排版。

## 2. 做对的，别动

1. **配色系统。** `--accent-primary #34597E`、moss、oxide、brass 四个语义色克制而有辨识度；图谱十色和语义色分开是对的，避免了"绿色既是健康又是 topic"。深色主题的提亮版本也调得准。
2. **字体策略。** `styles.css:21-30` 用 `unicode-range` 把 Archivo 限定在拉丁区，CJK 稳定回落到 PingFang / 微软雅黑，混排标题不会出现两套字形拼接。阅读弹窗用 Iowan / Palatino 衬线并限制 44-46rem 行长，这是全站最舒服的一屏。
3. **可访问性基本功。** 全局 `:focus-visible { outline: 2px solid var(--focus-ring) }`，`prefers-reduced-motion`、`forced-colors`、`hover: none` 都有分支。
4. **文档页与卡片预览弹窗。** 左目录、中正文、右出链，元信息用一个 pill 加一行 mono 路径，层级最清楚。图谱用 canvas 而不是 SVG 也是对的。
5. **EVA 模式作为"皮肤"的完成度。** HUD 单体、hex 网格、倒角、扫描线、开机序列，有完整的世界观，和 Institute 主题互不污染（`[data-theme="eva"]` 只改 token 与少量结构）。

## 3. 问题，按影响排序

### P1 · 顶部 chrome 太重，而且不粘

**现象。** 页面顶部永远叠着五层：topbar（7 个控件）→ 三核状态带 → 同步率进度条 → 一句解释文案 → tab 栏。内容起始位置实测：

| 视口宽 | 内容起始 y | 占视口 |
|---|---|---|
| 1532 px | 265 px | 31% |
| 846 px | 414 px | 43% |
| 390 px（手机） | ≈600 px / 844 | 首屏 100% 是 chrome |

390 px 下三核带竖排成三格，tab 栏折成三行，用户要滚过整整一屏才看到"想到什么就写在这"。

只有 topbar 是 `position: sticky`（`styles.css:874`），tab 栏不是。结果是滚下去以后导航没了，而 GLASS、MAGI 模式、语言切换这些装饰开关却永远在眼前。

**判断。** 三核状态是产品世界观的一部分，值得常驻，但不值得 120 px。解释文案（"这是就绪度，不是……"）是 onboarding 文案，不该每次都读。

**建议。**
- 把 topbar 压成一行 56 px：左品牌，中 tab，右项目选择器 + 一个 32 px 的三核状态簇（三个彩点 + 同步率数字，hover / 点击展开原来的三格详情）。
- 解释句移进状态簇的 tooltip 或首次访问的 dismissable 提示。
- tab 栏与 topbar 合并后自然 sticky；不合并也要 sticky。
- 控件分级：项目选择器是一级；主题 / GLASS / MAGI 模式 / CRT / 语言 / 体检收进一个"外观与环境"菜单（可以就是现在右下角那个玻璃调节面板）。
- 目标：桌面 chrome ≤ 96 px，手机 ≤ 120 px。

### P1 · 信息架构：总览页 = 收件箱 + 管理后台

**现象。** 总览整页 3600 px，依次是：写东西、待决定、研究线、建议操作、三个统计卡、已注册项目表（含 scratchpad 临时目录的完整长路径）、注册项目表单、`config.yaml` 22 行每行一个"保存"按钮、项目维护。Melchior 页里知识图谱排在第 6 张卡，前面是四个 metric 卡和三张空表。摄入队列页把"链接 / 上传文件 / Zotero"做成三张并列的整宽卡，实际上是一个表单的三个入口。Balthasar 正文里写着 `任务库文件位于 D:\文档\MindPalace（……）`。

**判断。** 日常页和设置页混在一起，导致最重要的东西没有被"最重要"地对待。系统路径、注册表、配置项都是设置，不是内容。

**建议。**
- 总览只留"写、决定、线、建议"四块，1200 px 以上做两栏：左"今天"（写 + 决定 + 建议），右"线 + 三核详情"。
- "已注册项目 / 注册 / 项目配置 / 项目维护"整体迁到运维页或新建"设置"页；配置表单改成一个表单一个保存（或自动保存 + 顶部 sticky 的"有未保存改动"条），22 个"保存"按钮是最刺眼的一处。
- Melchior 图谱置顶为 hero：左图谱、右词条列表；空状态的表（命题、时间线、溯源）整体折叠成一行，不要展开三个空表头。
- 摄入队列合并成一张卡 + 分段控件（链接 / 文件 / Zotero）。
- 路径类信息只在"设置"或 tooltip 里出现，正文里显示项目名。

### P1 · 视觉噪音：一切都是玻璃，一切都会浮起

**现象（代码）。**
- `index.html` 里 158 个 `.card`。每张卡：`backdrop-filter: blur() saturate() brightness()`（`styles.css:1455`）+ `::after` 折射边再做一次 backdrop-filter（`:1477-1493`）+ 指针跟随高光 `--glass-specular-layer`（`app.js:8846-8961`）+ `hover { transform: translateY(-2px) }` 弹簧曲线（`:1506-1510`）。
- `.stat-pill`、`.icon-btn` 同样有 backdrop-filter 和 `translateY(-1px) scale(1.02)` 的 hover（`:1027-1046`、`:1067-1100`）。
- GLASS 开启时页面上有 86 个带 backdrop-filter 的元素（实测）。
- body 底纹是 4 层 `background-attachment: fixed` 的 120 / 24 px 网格渐变（`:673-700` 附近）。

**判断。**
- 没有层级。容器、按钮、统计 pill 用的是同一种"贵"的材质，于是没有东西显得贵。
- 一张 1000 px 高的表格卡片因为鼠标经过而整体抬起，这是 widget 的行为，不是内容容器的行为。
- 浅色主题下卡片右侧出现暖黄色 sheen（截图 `文献与引用` 卡右缘），和冷灰蓝的 Institute 调性打架。
- 大屏上 120 / 24 px 双层网格把"纸"变成了绘图纸，和内容争注意力。
- 86 个 backdrop-filter 在集显 / 高 DPR 上有实际 GPU 成本，这是玻璃开关存在的原因，但默认就该少。

**建议。**
- 材质分三级，且只有三级：页面底（不透明纸，一层 32 px 极淡网格或干脆纯色）→ 内容卡（不透明、1 px 发丝边、`--shadow-sm`、无 hover 位移）→ 浮层（topbar、modal、tuner、toast 才用 backdrop-filter 和大阴影）。
- hover 抬升只留给可点的小卡（metric-box、action-row、词条行），内容容器一律不动。
- 删掉指针高光引擎，或只保留在 topbar 上。sheen 改成中性白。
- 玻璃继续作为可选项存在，但默认关。

### P2 · 排版与间距没有尺度

**现象（代码）。** `font-size` 157 处、56 个不同值（0.58–3.2rem）；没有 `--space-*` token，padding / margin 121 个不同值；radius 有 token 但 29 处硬编码 `border-radius: 0`（EVA 倒角覆盖）。正文层级普遍偏小：tab 0.86rem、卡片副标题 0.75rem、表格 0.78rem、pill 0.72rem，中文在 12 px 以下辨识度明显下降。

**建议。**
- 字号 6 档：12 / 13 / 14 / 16 / 20 / 28 px（rem 等价），UI 正文以 14 为基准，副标题不低于 13。
- 间距 4 px 基、8 档 token，所有 padding / margin 走 token。
- `.card-title` 从 1.18rem 降到 1.05rem，和 `.metric-label` 拉开对比而不是靠加粗。
- `.metric-label::after` 的 "+" 角标（`:1551-1560`）是无意义装饰，删。
- `.metric-value` 用 Archivo 600 + `tabular-nums` 是对的，保留。

### P2 · 表格、列表、空状态

- 表头米色底（`--bg-subtle #EDEBE2`）在浅色主题下像 Excel。改为无底色 + 1 px 下边线 + 小号灰标签。
- 嵌套滚动：知识图谱的词条列表、文献与引用列表都是卡内 260-300 px 的滚动盒（`.scroll-box.vh-260`），页面滚动条外再套一层。改为"显示更多"分页或让列表撑开页面。
- 长路径（scratchpad 临时目录 130 字符）在表格里换行两次。只显示项目名，路径进 tooltip 或中间省略。
- 空状态到处是"还没有 note。"一行字挂在一整排空表头下面。空表隐藏表头，给一句话 + 一个动作按钮（"开一条新的"已经存在，把它放进空状态里）。

### P3 · EVA 模式

- 红变体成熟，可以不动。
- 蓝变体（浅底 + 天空照片 + 65% 白玻璃）整体发白发青，正文对比度不足。照片加 20% 压暗，或玻璃 alpha 提到 80。
- 左侧竖排「三賢者統合思考体・同調率監視中」在 1532 px 下已经压进主内容左缘 40 px 内。按 `main-content` 留白判断，两侧留白 < 120 px 就隐藏。
- EVA 是彩蛋，不该占 topbar 两个按钮位。GLASS / MAGI 模式 / CRT 全部收进右下角调节面板。

### P3 · 知识图谱

- 480 px 高的画布只有中间 35% 有内容，标签互相覆盖不可读，是标准的 force-directed hairball。
- 建议：初始 zoom-to-fit；节点数 > 80 时默认只画度数前 N 的标签，其余 hover 才出；hover 高亮一跳邻居、其余降到 20% 不透明；概念（深蓝）和文献（青绿）两色太近，文献换成图谱色板里的 violet 或 amber。
- 图谱的 7 个视图 pill（图谱 / 总览 / 词条 / 链接 / 命题 / 标签 / 断链）作为卡片右上角的小按钮组过于隐蔽，这是 Melchior 的主导航，应当是卡片内的一行分段控件。

### P3 · 细节清单

- 运维页复选框贴着标签（"☑Ollama"），缺 `gap`。
- 旧版截图里版本徽标 + "有新版本" pill 两个胶囊挤在 logo 旁，升级提示应是 topbar 右侧的一个点或进入菜单。
- "浏览中" 警告 pill 与 "三核同步" pill 同权重并排；"浏览中" 应作为项目选择器内的后缀（`Algebra+Duality+Defect · 浏览`）。
- `☾` 主题按钮和文字按钮混排，宽度不齐。
- `.radar-context`（`styles.css:1924`）按定义评审：无边框、muted、0.85em，作为"上下文行"与 action-row 的层级区分是对的。未实际渲染。
- 玻璃调节面板里 "背景 · 换一张" 在 Institute 主题下显示"这个模式没有可用图片"，功能不可用时应隐藏而不是解释。

## 4. 理想形态（不受重构幅度限制时我会怎么做）

**方向：把 "Institute" 做到底。** 一个研究控制台应该像一页排得很好的期刊加上一排仪表，而不是一块 HUD。

1. **壳。** 56 px 单行 header：品牌 · tab · 项目选择器 · 三核状态簇 · ⋯ 菜单。内容 `max-width: 1280px`，纸色底，一层极淡网格或没有网格。
2. **材质。** 两种海拔：纸面（内容）和浮层（modal / toast / tuner）。玻璃只给浮层，默认关。hover 只改边框色和阴影，不位移。
3. **字。** UI 用 Archivo 14 px 基准、6 档字号；阅读面（文档页、卡片预览、简报）用现在的衬线栈。数字一律 `tabular-nums`。
4. **总览。** 两栏：左"今天"（写 + 决定 + 建议），右"线 + 三核详情"。设置、注册表、config 全部出走。
5. **Melchior。** 图谱 hero 占首屏 60% 高，右侧词条列表随图谱筛选联动；命题 / 时间线 / 溯源折叠成一条摘要行。
6. **摄入 / 雷达。** 一张"加一篇"卡 + 分段控件；雷达的"运行扫描"是页面唯一的一级按钮，其余全部二级。
7. **EVA。** 保留为完整皮肤，从调节面板开启；开启时允许它改结构（HUD、竖排字、倒角），Institute 下这些结构一律不存在。

## 5. 落地顺序

1. **Chrome 减负（约一天）。** 合并 topbar 与 tab 栏、sticky、三核收成状态簇、装饰开关进菜单。用户每一屏都受益。
2. **材质分级（约一天）。** 卡片不透明、去 hover 位移、去指针高光、玻璃只留浮层、网格减一层。
3. **IA 拆分（两到三天）。** 总览拆出设置页、Melchior 图谱置顶、摄入表单合并、空状态重做。
4. **尺度 token（渐进）。** 字号 / 间距 token 化，随每次触碰的文件顺手迁移。

## 6. 实施记录（2026-09-02）

评审中的建议已全部落地，未提交。改动只在 `src/magi/ui/static/{index.html,styles.css,app.js}` 与两个设计锁测试文件。

**壳层。** 一行 sticky 顶栏：品牌 · 分区 · 项目选择器 · 三核状态簇 · 外观。三核状态带、同步条、解释句合并成状态簇的弹层；主题 / MAGI 模式 / 玻璃 / 模糊 / 不透明 / CRT / 语言 / 背景 / 环境体检收进外观面板。内容起始位置从 265 px 降到约 60 px（1532 px 宽），手机宽度从整屏降到约 120 px。

**材质。** 按 Apple Liquid Glass 的层级规则：玻璃只给悬浮层（顶栏、两个弹层、弹窗、提示），内容卡片是不透明纸面，无 hover 位移、无指针高光、无折射边。弹层从顶栏里提出来作为 sticky 壳的同级元素，否则嵌套在 backdrop-filter 元素内的弹层只能模糊父元素的内容，模糊不到页面。GLASS 开启时 backdrop-filter 元素从 86 个降到 15 个。分区条与所有分段控件改为胶囊轨道加实色选中 pill。

**分区命名。** Institute 主题下按功能命名（总览 / 知识 / 任务 / 检索 / 雷达 / 摄入 / 运维 / 文档），核心名进 tooltip；MAGI 模式下仍用 Melchior / Balthasar / Casper 加频道号。

**信息架构。** 总览两栏（≥1200 px），只留随手记、待决定、建议操作、研究线与三个计数；已注册项目、注册项目、项目配置、项目维护移到运维页。配置表单改为一次保存（改动行标记、页脚计数、保存 / 放弃）。知识页图谱置顶为 hero，视图切换改为分段控件，初次布局后自动缩放到画布，节点超过 80 个时只给度数前 40 的节点标签，文献节点改用铜色与概念蓝拉开。摄入页三张加篇卡合并为一张带分段切换的卡。空表隐藏表头，只留一句话。注册表把路径缩到名称下方并从中间省略。运维页可选组件卡片增加环境体检入口。

**尺度。** 引入 `--text-xs … --text-xl` 六档字号与 `--space-1 … --space-8` 八档间距；Institute 主题下所有小于 12 px 的字号统一到 token。

**文案。** 90 条可见文案改为产品口吻，中英同步；去掉界面上的设计解释。

**测试。** `tests/test_liquid_glass.py` 三条锁改为新契约：指针高光改锁在顶栏而不是卡片；折射边改锁在弹窗；`.card::before` 装饰线的几何锁替换为 `test_cards_are_paper`（卡片不透明、无 backdrop-filter、无 hover）。这三条锁定的都是材质实现的外观，不是产品决策，改锁的理由写在各自的 docstring 里。`tests/test_one_thing_one_word.py` 的同文白名单加入三个 MAGI 模式的核心名。全量 2726 项通过。
