---

**Do not hand-author these files.** `_index.md` is generated — `magi wiki
reindex`, `magi lint --fix` and `magi init` all render it through one function,
and anything you write above `## Recent Changes` is replaced on the next pass.
This template records the shape so the generated output can be recognised, not
so it can be typed.

Two parts behave differently:

*   **`## Contents`** is always rebuilt from each file's frontmatter — `title`
    is not used here, the link text is the filename. The date column reads
    `updated`, then `ingested`, then `created`.
*   **`## Categories`** appears only when the frontmatter actually separates
    the files. With the current schema (`category: concept` on every concept
    card, `type: papers` on every reference) one directory is usually one
    bucket, and a "Categories" list holding everything is the Contents table
    again wearing a hat — so it is omitted.
*   **`## Recent Changes`** is *yours*. Nothing generates it and every rebuild
    carries it through untouched. This is the one place in the file worth
    writing in by hand.
